# Algoritmos y Estructuras de Datos

Repositorio con material de estudio, apuntes y resoluciones de la materia Algoritmos y Estructuras de Datos. 

El objetivo de este repositorio es pasar a limpio los conceptos teóricos y prácticos de la cursada. En particular del segundo cuatrimestre. 

## 📚 Contenido del Repositorio

*   **Clases / Apuntes:** Desarrollo teórico sobre arquitectura de memoria (Stack vs. Heap), punteros, memoria dinámica y análisis de complejidad algorítmica (Big-O).
*   **Ejercicios Individuales:** Implementaciones prácticas en C++ de estructuras de datos estáticas (`std::array`, matrices) y dinámicas (Listas enlazadas, Pilas LIFO, Colas FIFO) construidas con Nodos.

## 🛠️ Tecnologías y Conceptos Abordados

*   **Lenguaje:** C++ moderno.
*   **Conceptos Clave:**
    *   Streams.
    *   Estructura de control For.
    *   Arreglos, vectores y matrices.
    *   Structs.
    *   Gestión de memoria y aritmética de punteros.
    *   Paso por referencia y uso de referencias constantes (`const &`).
    *   Punteros.
*   **Temas informarles de clase que hacen a lo profesional.**
